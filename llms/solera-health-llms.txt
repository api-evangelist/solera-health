# Solera Health

> Solera Health is a preventive-care benefits manager that acts as a single integration point
> between health plans, employers and a curated network of non-clinical digital health providers.
> Its HALO omni-condition management platform lets a payer or employer contract, configure, enroll
> and report across eight condition networks spanning 25+ partner point solutions, alongside
> customer-contracted solutions Solera did not source.

Generated by API Evangelist on 2026-08-28 from the apis.yml profile and repo artifacts, because
Solera Health does not publish an llms.txt of its own (https://www.soleranetwork.com/llms.txt
returns 404, as does https://www.gosolera.com/llms.txt).

## API surface — read this first

Solera Health has NO public developer program. There is no developer portal, no API reference, no
OpenAPI, no GraphQL SDL, no AsyncAPI, no Postman collection, no SDK, and no MCP server.

An API does exist and it is reachable: https://api.soleranetwork.com is a live Azure API Management
gateway on Solera Health's own domain (DNS CNAME to solera-api-gateway.portal.azure-api.net), used
for payer, employer and digital-health-partner integrations into HALO. Every anonymous request to
it returns the Azure APIM envelope {"statusCode":404,"message":"Resource not found"}, and the
matching developer portal at https://solera-api-gateway.developer.azure-api.net/ still serves
Azure's default "The content hasn't been published yet" placeholder. Access requires a signed
partner or payer integration agreement and a subscription key.

Do not confuse Solera Health (soleranetwork.com, healthcare benefits) with Solera Holdings
(solera.com, na.api.solera.com, solera.vin — automotive claims and vehicle lifecycle). They are
unrelated companies. The Solera developer documentation and swagger specs that turn up in search
belong to Solera Holdings and must not be attributed to Solera Health.
